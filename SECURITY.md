# Seguridad

MPASM Live ejecuta un ensamblador local sobre fuentes de la carpeta de trabajo. La ejecución requiere una carpeta de confianza y Windows; la extensión no descarga ni instala ejecutables automáticamente.

Para comunicar una posible vulnerabilidad, utiliza la opción de reporte privado de vulnerabilidades de GitHub si está habilitada en el repositorio. Si no aparece, solicita un canal privado mediante un issue sin publicar detalles de explotación ni información sensible.

No incluyas contraseñas, tokens, archivos privados o binarios de terceros en los informes. Consulta README.md para conocer las plataformas y funciones verificadas; esta versión todavía necesita validación en más equipos.
